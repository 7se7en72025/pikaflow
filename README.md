# PikaFlow

A statically typed programming language and LLVM-based compiler written in C++.

This learning project draws inspiration from [Pikapika](https://github.com/7se7en72025/pikapika) and [Goof](https://github.com/sneaky-potato/goof). The language syntax is still being designed.

## Status

Repository initialized. Compiler implementation has not started.

## First milestone

Use LLVM's C++ API to generate and verify a small LLVM IR module, then compile it into a working executable on Windows x64.

Reference: [LLVM language frontend tutorial](https://llvm.org/docs/tutorial/).
